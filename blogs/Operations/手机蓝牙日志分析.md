## 获取手机蓝牙数据传输日志

以 红米/小米 手机为例

### 手机开启开发者模式

一般为进入 手机设置-系统设置-系统信息-全部参数与信息 

多次点击 os版本 那一栏，会提示已开启开发者模式

一般 小米/红米 手机开启方式差不多，实际可网上查

### 开发者模式开启蓝牙日志

打开蓝牙数据包日志；已启用

### 手机拨号

```
*#*#5959#*#*
```

开启监听

再次拨号

```
*#*#%5959#*#*
```

结束监听并导出日志

### 日志位置

``内部存储位置/MUUI/debug_log/``

一般自动导出是 zip 压缩包，包含了该目录全部日志。也可能没有压缩包，直接有一份log文件，不同手机型号有差异；

实际可以直接在 debug_log/common/common.android.bluetooth/ 下，文件名一般为 btsnoop_hci_{时间戳}.log

### 日志查看

一般用 WireShark 等工具查看日志；

也可以直接丢ai进行分析
